AMG CloudLink is a .NET 10 WPF desktop application packaged as MSIX. A packaged desktop application runs at medium integrity and has to declare runFullTrust. The app uses it only to run as an ordinary desktop program: it shows its window, opens the default browser for sign-in, listens on a loopback port for the sign-in redirect, and writes the downloaded files to the folder the user chooses. It installs no drivers or services, registers no background tasks and never asks for elevation.
