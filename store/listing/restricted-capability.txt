AMG CloudLink is a classic Windows desktop application (.NET 10, WPF) packaged as MSIX. Its only executable, CloudLink.exe, is started as a full-trust desktop process (EntryPoint Windows.FullTrustApplication), which is how a WPF application runs inside a package; runFullTrust is declared only for that. It is the only restricted capability in the package.

What the app does with it: it runs as the signed-in user at medium integrity, shows its window, opens the default browser so the user can sign in to Microsoft or Google on their own pages (OAuth with PKCE), listens on a loopback port only while that sign-in is in progress to receive the redirect, calls Microsoft Graph and the Google Drive API over HTTPS, and writes the downloaded files into the folder the user chooses. Settings and the encrypted sign-in tokens are kept in the app's own data folder.

What it does not do: it never asks for elevation, installs no drivers or services, registers no background tasks or startup entries, changes no system settings, does not touch other apps' data, and never runs or opens the files it downloads.
