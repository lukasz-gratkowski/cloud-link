Requires an internet connection and a web browser. Most OneDrive links require a Microsoft account; links from an organisation's OneDrive or SharePoint that are shared with anyone with the link do not. Google Drive™ links require credentials that you create once in the Google Cloud console. Details are under "Accounts and access" below.

AMG CloudLink downloads shared folders and files from OneDrive, SharePoint and Google Drive to your Windows PC, complete and verified.

A browser downloads a large shared folder as a single zip archive, which can fail or time out, and a dropped connection means starting over. CloudLink downloads each file individually, resumes anything that was interrupted, and verifies every file before marking it complete.

KEY FEATURES
• Complete folders. The shared folder is recreated on disk with all its subfolders. Links to single files are supported as well.
• Resumable downloads. After a lost connection, a stop, or a restart of the PC, CloudLink continues where it left off. Completed files are never downloaded twice.
• Verified files. Each file is checked against the size and checksum reported by the service and downloaded again if it does not match. A file receives its final name only when it is complete and verified.
• Automatic recovery. Network errors, stalls, throttling and server errors are retried at increasing intervals. If the network drops, CloudLink waits for it to return.
• Clear progress. Overall progress with speed and time remaining, a status for every file, and a filter for the items that need attention.
• Parallel downloads. Four files at a time by default, adjustable in Settings.
• Several links at once. Paste one link per line, or drop a link onto the window.
• Google documents. Docs, Sheets and Slides are exported as .docx, .xlsx and .pptx files.

ACCOUNTS AND ACCESS
OneDrive and SharePoint. A link from an organisation's OneDrive or SharePoint that is shared with anyone with the link opens without any account, as it does in a private browser window. Other OneDrive links require a Microsoft sign-in, which takes place in your browser; with a personal Microsoft account no further setup is needed. Microsoft's consent page states that the app can edit your files, because Microsoft opens share links only for apps that hold a read and write permission. CloudLink only downloads and never uploads, changes or deletes files. The same page describes the app as "unverified", which refers to Microsoft's publisher verification programme, not to the software itself.

Work and school accounts. An organisation's link that is not shared with anyone opens only for accounts that the organisation allows, usually its own work or school accounts. Many organisations require an administrator to approve an app such as CloudLink once before their users can sign in; Microsoft's sign-in page then reports that admin approval is needed.

Google Drive. CloudLink has no Google registration of its own, so access is set up once in your own Google Cloud console: an API key for links that anyone can open, or an OAuth client for private links. The setup takes ten to fifteen minutes and is currently free of charge. The user guide on the product website describes both options step by step.

REQUIREMENTS AND LIMITATIONS
• Windows 10 or 11, 64-bit.
• Google Forms, Sites and My Maps have no downloadable file content and are skipped.
• Google documents larger than 10 MB can be exported only when signed in, not with an API key.
• CloudLink downloads only what a share link makes available to you. You are responsible for having the right to download and keep the content.

PRIVACY
CloudLink runs on your PC and communicates only with Microsoft and Google, for the links you provide. It contains no telemetry and no advertising, and sends nothing to AMG Cloud Engineering. Sign-in takes place on Microsoft's or Google's own pages in your browser, so CloudLink never sees your password. Sign-ins are stored on your PC, encrypted for your Windows account. Opening a link after signing in is recorded against your account, as it is when you open the link in a browser.
