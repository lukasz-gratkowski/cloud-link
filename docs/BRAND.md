# Brand

## Logo

<img src="../src/CloudLink/Assets/CloudLink.png" width="128" alt="CloudLink logo">

A white cloud with a downward arrow on a rounded tile: *things come down from the cloud*. The tile's
gradient runs from azure at the top left to violet at the bottom right.

- Vector source: `LogoImage` in `src/CloudLink/App.xaml`.
- Icon and PNG: generated by `tools/make-icon.ps1` into `src/CloudLink/Assets` (16 to 256 px; the arrow is
  drawn heavier at 24 px and below so it stays legible).
- Keep clear space of a quarter of the tile's width around it. Do not recolour, rotate or outline it.

### Logo files for other places

`tools/make-icon.ps1` also writes three 215 x 215 PNGs to `branding/`:

| File | What it is | Use |
|---|---|---|
| `CloudLink-logo-215-opaque.png` | The brand gradient fills the whole square. No alpha channel. | The Microsoft Entra app registration (**Branding & properties → Upload new logo**), which Microsoft's permission page shows. |
| `CloudLink-logo-215-flat.png` | The same, on a single colour (azure). No alpha channel. | Where a single-colour background is wanted. |
| `CloudLink-logo-215-transparent.png` | The rounded tile with transparent corners. | Places that put the logo on their own background. |

Microsoft publishes no rules for the app registration logo itself. Its page for enterprise applications,
where that logo also ends up, asks for exactly 215 x 215 pixels, PNG, at most 100 KB, and recommends a solid
colour background with no transparency. All three files meet the size, format and weight; the opaque and flat
ones have no transparency, and the flat one is the literal reading of "solid colour". Only a listing in the
Microsoft Entra application gallery asks for a transparent logo (and a second one of 150 x 122).

## Colours

| Role | Dark theme | Light theme |
|---|---|---|
| Brand azure | `#2E7BFF` | `#2E7BFF` |
| Brand violet | `#7B4DFF` | `#7B4DFF` |
| Arrow blue | `#3D6BFA` | `#3D6BFA` |
| Success | `#3DD68C` | `#1A9F53` |
| In progress | `#6AA5FF` | `#2E6BE6` |
| Warning | `#FFB84D` | `#B86E00` |
| Error | `#FF6B6B` | `#D13438` |
| Idle | `#7F8794` | `#8A8F98` |
| Text | white, 96% | `#101828`, 90% |
| Card surface | white, 7% | white, 85% |

The brand gradient (azure → violet) is reserved for three things: the logo, the one primary action on a
screen, and progress. Status colours always come with a word; colour is never the only signal.

## Interface principles

1. **One primary action.** Each screen has a single gradient button. Everything else is quiet.
2. **Top to bottom is the order of use.** What and where, then what is happening, then the detail.
3. **Say what is happening, then what to do.** Every state has a headline and a sentence underneath.
4. **Motion means work.** Things move only while CloudLink is working, and stop when it stops. Motion
   follows the Windows animation setting.
5. **Nothing is lost.** Stop, close and failure all leave the user able to continue.

Type: Segoe UI Variable (the Windows system font). Icons: Segoe Fluent Icons, falling back to
Segoe MDL2 Assets on Windows 10.
